# #662: 内部マップの街でもちずのかけらを得る

## 範囲と根拠
既存の #662 の不具合修正。origin/dev cc0ce4b が基点。
edge はフィールドの街到着、およびフィールドの街タイルからのゲート遷移で lastTown を確定する。しかし web は移動後がフィールドの town の場合しか探索メモを増やしていない。

## 変更
- 移動応答へ任意の `townArrival: { x: number; y: number }` を追加。座標は内部座標ではなく街のフィールド座標。既存の lastTown 確定に成功した2経路でだけ返す。通常歩行、内部の town 床、非街ゲート、施錠失敗、内部からの退出では返さない。帰還先、HP/MP、報酬の権威処理や保存スキーマは変更しない。
- web は応答の townArrival に基づき、街周辺3×3リージョンと訪問街を重複なしで追加し、lastTown 表示メモを合わせる。位置/mapId と HP/MP はそのまま。回復表示は既存の healed が true の時だけ。ゲート入場は「街に着いた」と表示する。
- 新規かけら/初訪問は既存と同じ即時保存、通常のdebounce保存も維持。再訪でメモは増殖しない。保存失敗の既存再試行挙動は変えない。
- 既存内部座標の探索判定を流用せず、街到着を1つの応答契約で扱う。旧clientは追加キーを無視する。新webは新edgeの応答が必要なので、将来配備時はedgeを先に更新する。本作業で配備しない。

## 非対象
#658/#659の他worktree、管理PDS投入、クエスト報酬・権威schema・宿料金・回復ルール・一般UI改造・テレポート・退出時のlastTownルールは変更しない。新たな権限/外部サービス/移行は不要。

## 受入
- ゲート経由の別地方の街でも、その街の3×3が地図の表示対象となり訪問先が保存される。
- 入場だけではHP/MPが回復せず、内部位置もフィールド位置に置換されない。
- 再訪で重複なし。通常の街到着は従来の回復を維持。
- 非街ゲート/内部歩行/施錠失敗でかけらなし。
- edge回帰、探索メモと保存/地図表示対象の回帰、web必須gateを実行。実devログイン操作は実データ変更を伴うため実施せず、未確認と明記。
