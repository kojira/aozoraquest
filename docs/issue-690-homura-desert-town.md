# 砂漠の町「ほむらの街」 (#690)

## 承認と目的
オーナー依頼: 物語「七色の鳥」の赤い鳥ほむらの舞台として、地図に砂漠の町を作る。既存の町を改名して「ほむらの街」にする。場所は任された。
親の決定: region 26「かわせみの里」(320, 448)。ふたばの村 (211, 340) から とんぼの原 (192, 448) を経由して二つ先。
赤い鳥の SNS 連携クエストは物語が未確定のため範囲外。

## 表示元の事実 (公開 PDS の読取で確認、書込みなし)
- staging の地形は主管理者 PDS の `app.aozoraquest.world.map` (1024², parts 13 種、towns 差分なし) が同梱地図より優先 (web `loadAuthoredWorld`、edge `ensureAuthoredWorld`)。**同梱の地形を変えても staging には出ない。**
- 町名は towns 差分が無いため、同梱 `WORLD_DATA` (= `TOWN_NAMES[region]`) がそのまま表示される。**同梱データの改名で web / edge とも反映される。**
- 町名に依存する進行・発見記録・クエスト・NPC・ゲートは無い (座標 / region がキー)。移行は不要。
- 保存済み地図の (320, 448) は町タイル。周囲は平原・林が中心で、西に水と縦の橋、東に山。

## 変更
1. `TOWN_NAMES[26]` と生成済み `world-data.ts` の該当町名を「ほむらの街」に。生成アルゴリズム・同梱地図 (ノイズ由来) は変えない。
2. `/admin/map` の「地図を編集」に **「ほむらの街の砂漠を入れる」** ボタン。既存の「ふたばの村を入れる」と同じく、下書きへ挿入 → 画面で確認 → 管理者が明示的に「保存」。
   - 範囲: 町を中心にした決定的な楕円 (横半径 16・縦半径 12)。縁は座標ハッシュで ±2 揺らし、角ばらない自然な輪郭にする。
   - 置き換えるのは地形が plains / grove / forest で、通行可能な (walkable が false でない) パーツのマスだけ。町・水・池・山・橋・雪原などは変えない。他の町の座標も除外。
   - 砂漠パーツは、既存の parts にある通行可能な desert を再利用する。無ければ既存の `appendBiomePart` で末尾に追加する (番号衝突の拒否も既存どおり)。
   - 置き換え元も置き換え先も通行可能なので、ふたばの村からの徒歩到達性は変わらない。
   - 町 (320, 448) が町タイルでない地図 (編集で消した等) では何もせず理由を表示。
   - 再度押しても、置き換え対象が残っていなければ変更も parts 追加もしない (「既に入っています」)。
3. 砂漠は既存 desert (平原と同じ遭遇率・通行) を使う。新しい地形・効果は追加しない。

## しないこと
実 PDS への保存、既存プレイヤーの位置・地図取得状態・進行の変更、自動移行、他の町の改名、赤い鳥クエスト、main / 本番の変更。

## 検証
- core: 町名が region 26 で「ほむらの街」、`TOWN_NAMES` と `WORLD_DATA` の一致 (既存テスト)。
- web unit: 同梱地図に対して挿入 → 砂漠化したマスは元が plains/grove/forest だけ、町・水・山・橋は不変、ふたばの村から ほむらの街まで徒歩経路が存在、再実行で変化なし・parts 追加なし、砂漠パーツが無い parts では 1 つだけ追加。
- 実画面: 隔離環境の `/admin/map` でボタン → 下書きに砂漠が見える、World で町名「ほむらの街」と砂漠が見えるスクリーンショット。

## 反映手順 (マージ・配備後、オーナー操作)
1. https://dev.aozoraquest.app/admin/map を開く (主管理者でログイン)。
2. 「ほむらの街の砂漠を入れる」→ 地図で確認 →「保存」。
3. World で ほむらの街へ。町名は配備だけで反映、砂漠は保存後 (edge は最大 5 分) に反映。

## 実装/検証結果
- 楕円は横半径 16・縦半径 12、輪郭を角度の正弦で最大約 ±20% 揺らす。同梱地図では 394 マス、staging 保存済み地図 (公開読取のコピー) では 431 マスが砂漠になり、平原・林・森以外の変更 0、ふたばの村から徒歩到達可、既存の砂漠パーツ (index 9) を再利用し parts 追加 0、二度目は変更 0。実 PDS には書いていない。
- 隔離 fixture の実 `/admin/map` → 挿入 (送信なし) → 再押下で「既に入っています」→ 保存 (1 回だけ PUT) → World で「🏘 ほむらの街」と砂漠の絵を表示 (E2E `homura-desert-town.spec.ts`)。
